# The Debt Hunter: Character Reference Prompts

Generate each prompt 4-8 times, keep the best one, and save it to `stories/debt_hunter/refs/<name>.png`.
Those reference images are then given to the image model for every episode illustration, so each character
keeps the same face, hair and outfit across the whole season.

**Settings:** 1536x1024 (wide, room for a full body and a face close-up), a text-to-image model such as Qwen Image
or Flux in WanGP. Use a fixed seed once you like a result, so you can make small prompt tweaks without losing it.

**Negative prompt for every sheet:**
> text, letters, labels, watermark, logo, signature, busy background, scenery, multiple different characters,
> blurry, low quality, deformed hands, extra fingers, extra limbs, distorted face, cropped head, cropped feet

## Tips
- **Judge the face first.** Pick the sheet where the face looks best; small outfit fixes are easy later.
- **Keep the outfit simple and distinctive.** The orange straps on Cass's jacket and Mara's silver ponytail are
  what make them recognizable in small, fast-moving shots.
- **Check the hands and the Crest marks.** Redo any sheet with extra fingers or a missing mark.
- **Once you lock a reference, never change it mid-season.** Change prompts, not references.
