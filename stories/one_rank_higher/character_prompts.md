# One Rank Higher: Character Reference Prompts

Generate each prompt 4-8 times, keep the best one, and save it to `stories/one_rank_higher/refs/<name>.png`.
Those pictures are given to the image model for every illustration, so each character keeps the same face, hair
and outfit all season.

**Settings:** 1536x1024, a text-to-image model such as Qwen Image in WanGP. Use a fixed seed once you like a result.

**Negative prompt for every sheet:**
> text, letters, labels, watermark, logo, signature, busy background, scenery, multiple different characters,
> blurry, low quality, deformed hands, extra fingers, extra limbs, distorted face, cropped head, cropped feet
